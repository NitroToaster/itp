# Use of AI Tools in Release 2

During the development of this project, we made use of several AI-powered tools to support, accelerate, and improve our workflow. These tools served as assistants rather than replacements for human decision-making, helping the team increase productivity, explore alternative solutions, and maintain clear documentation.

How each individual has used different AI-powered tools may differ. However, these are our common ambitions when using these tools.

All final design choices, implementation details, and validations were made by the project team to ensure quality, correctness, and accountability.

## Tools and Their Use


### GitHub Copilot (Integrated in VS Code)

GitHub Copilot was used as a real-time coding assistant during implementation.
Its role included:
- Generating boilerplate code, such as repetitive class or method structures
- Offering implementation ideas for common programming patterns
- Suggesting syntax corrections and small optimizations during development

Copilot helped improve development speed, especially in early iterations or when setting up repetitive constructs. However, all generated code was reviewed, tested, and adapted by the team to ensure alignment with our coding standards and project design.

### ChatGPT

ChatGPT was used primarily as a knowledge and writing assistant throughout the project.
Its contributions included:
- Providing clarifications and explanations for programming concepts and framework behavior
- Assisting in drafting and refining documentation, such as README.md, workflow.md, and work-practices.md
- Helping formulate and refine user stories and acceptance criteria for features
- Supporting debugging discussions by analyzing error messages or proposing diagnostic approaches

All suggestions and explanations provided by ChatGPT were verified independently by the team before implementation.

### Claude.ai

Claude.ai was used as a secondary AI collaborator, offering alternative perspectives and refinement support.
Its key roles were:
- Reviewing code structure and recommending improvements for clarity and maintainability
- Providing alternative solutions or conceptual approaches to complex problems
- Assisting with editing and polishing written documentation to ensure clarity, tone consistency, and professionalism

Claude’s feedback was used selectively — always cross-checked with our project context and technical requirements. 


## Responsible Use and Verification

The team followed responsible AI usage practices throughout development:
- No AI-generated code was accepted without team review and testing
- No sensitive or proprietary information was shared with any AI system
- All core design decisions, code logic, and validation were carried out by human team members
- AI tools were treated as productivity aids, not as authors or decision-makers

## Summary

AI tools contributed to:
- Faster implementation and prototyping
- Improved understanding of concepts and patterns
- Higher-quality documentation and communication

However, the final responsibility for correctness, design integrity, and ethical use rests entirely with the project team. All AI-generated outputs were validated, reviewed, and adapted before inclusion in the project.
