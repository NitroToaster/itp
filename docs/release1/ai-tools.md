Use of AI Tools in release 1:

During the development of this project, we made use of AI-powered tools to support and improve our workflow. Specifically, we used:

GitHub Copilot (integrated in VS Code): For code suggestions, boilerplate generation, and quick implementation ideas.

ChatGPT: For explanations of programming concepts, drafting user stories, and assistance with documentation.

Claude.ai: For alternative perspectives on problem-solving, refining code structure, and reviewing written content.

These tools were used as supportive aids, while the final design decisions, coding, and validation were done by the project team.
